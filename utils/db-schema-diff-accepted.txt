# Accepted differences between a fresh database (structure.sql) and one migrated
# from 0.44.1 through utils/db-schema-update, as keys printed by db-schema-diff.php.
# One key per line, the reason in a comment above each group. An entry that no
# longer matches a difference fails the diff, so remove it when it is fixed.
# An entry accepts the key, not the detail, so it also hides any later change
# reported under the same key (for example a collation change of user.username).
# Adding an entry needs the maintainer's agreement.
